libtooling-wrapper is a C++20 module wrapper generated by the modulizer tool
(`--wrapper` mode). It re-exports clang/llvm declarations via
`using ::clang::...;` / `using ::llvm::...;` so that downstream C++20-module
projects can `import libtooling;`.

The re-exported clang/llvm API surface originates from the LLVM Project and is
licensed under the Apache License 2.0 with the LLVM Exceptions (see the LICENSE
file in this directory, which is the LLVM Project license). The wrapper
generation logic itself is part of modulizer
(https://github.com/j4niwzis/modulizer), which is free software.

When consuming this package via CPM.cmake:

    CPMAddPackage(NAME libtooling-wrapper
      GIT_REPOSITORY https://github.com/j4niwzis/libtooling-wrapper.git
      GIT_TAG main
      GIT_SHALLOW TRUE)

    target_link_libraries(your_target PRIVATE libtooling)

    // your_target source
    import libtooling;
